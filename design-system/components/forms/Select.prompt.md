**Select** — native select with brand chrome (custom chevron). Powers the year/make/model precision mode.

```jsx
<Select label="Year" placeholder="Select year" options={[
  { value: '2024', label: '2024' },
  { value: '2023', label: '2023' },
]} />
```

Pass `options={[{value,label}]}` or `<option>` children.
