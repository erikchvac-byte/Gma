## What Went Well

- **Foundation-first layering held perfectly.** tokens (6-1) → primitives (6-2) → surfaces (6-3). Each story was pure consumption of the one before, with nothing to invent. Hard scope boundaries were grep-verified — zero cross-bleed into untouched components.
- **Behavior-preservation as a discipline.** 6-3 re-skinned six live surfaces with zero data/logic changes; DealCard null-handling and the vehicle auto-resolve cascade stayed byte-for-byte equivalent in outcome.
- **The accessibility upgrade is real, not cosmetic.** VehicleSelector went inline-panel → proper `role="dialog"` bottom sheet: focus trap, Esc, scrim, focus-return to the gear, always-visible focus rings, and the `aria-valuetext`-only-when-string rule.
- **"Copy verbatim, don't reconstruct" carried forward from 6-1 into 6-2** as an explicit, documented lesson — and prevented a class of typo bugs in the CSS port.

## What Was Hard / Key Lessons

1. **The untyped CSS surface is a latent-bug class.** CSS custom-property names *and* `gma-*` class names in JSX are caught by nothing — not `tsc`, not `vite`. Mitigated with verbatim copy + sentinel greps, but this is the same family of risk as Epic 4's "silent-failure contracts" lesson, one layer down. **Lesson:** treat any stringly-typed contract (CSS classes, token names) as needing a presence check, because the compiler won't help.
2. **The vendored design-system import had source-quality defects:** prose vs CSS conflicts (ruling: CSS wins), wrong radius/shadow values in `_imported-CLAUDE.md.txt`, a missing `--border-field` token (added in 6-3), and 4 *identical* Public Sans woff2 files (no real weight differentiation — an unresolved source-asset gap). **Lesson:** a design export is input material, not a contract; reconcile and declare the authoritative source before consuming it.
3. **A shipped implementation delta surfaced and was corrected.** VehicleSelector had shipped as an inline panel, not the ruled bottom sheet; 6-3 closed the gap, which forced lifting vehicle/sheet state up to `App` (the persistent Header must render outside DealFeed's early returns).
