# Decision Log — Gma's Helper PRD

## Pre-PRD Spike (2026-06-08)

### SPIKE-001: Crawl/audit method validated
**Decision:** Own-site crawling only for v1. Time-windowed happy hours as primary deal type; any active deal today as secondary.
**Context:** Dispensary sites audited: Wild Seed Wellness, Remedy Tulalip, Hangar 420, Buds Garage, Cascade Kropz. Weedmaps/Leafly deal detail not available in static HTML.
**Findings:**
- ~60% of dispensaries serve deal data as plain crawlable HTML (no JS rendering required)
- True time-windowed happy hours confirmed at: Remedy Tulalip (7–8am), Hangar 420 (9pm–close)
- All-day daily deals common (Wild Seed Wellness, Buds Garage)
- Weedmaps/Leafly aggregator data requires JS rendering or private API — deferred to Phase 2
**Rationale:** Simplest viable approach for R&D validation. Phase 2 can add aggregator coverage if concept proves out.

### SPIKE-002: Skip dispensaries without crawlable deal data

**Decision:** Dispensaries whose deal data lives only on third-party menu subdomains (e.g., Weedmaps-hosted menus) are excluded from v1 coverage.
**Rationale:** Keeps v1 scraping stack simple and avoids JS-rendering dependency during R&D phase.

## PRD Draft (2026-06-08)

### PRD-001: Deal priority order — Happy Hours primary, Daily Deals secondary
**Decision:** Product surfaces Happy Hours (time-windowed deals) first, Daily Deals (all-day) second.
**Rationale:** Time-windowed deals are the highest-urgency signal; all-day deals fill the feed when no Happy Hours are active.

### PRD-002: Origin point fixed at zip 98270 for v1
**Decision:** [ASSUMPTION] All Road Distance and Gas Cost calculations use zip 98270 centroid as origin. No browser GPS.
**Rationale:** Simplest approach for R&D validation. All test users are in Marysville. Geolocation flagged as Phase 2 if concept validates.

### PRD-003: Age gate — button-click only
**Decision:** [ASSUMPTION] 21+ confirmation overlay on first load, localStorage-persisted. No identity verification.
**Rationale:** Standard approach for informational cannabis sites at R&D scale.

### PRD-004: Scraper interval — 60 minutes
**Decision:** [ASSUMPTION] Scraper runs every 60 minutes.
**Rationale:** Happy Hours are hours-long windows; 60-minute refresh is sufficient for accurate active-deal status at R&D scale.

### PRD-005: Distance filter default 25 miles, max 50 miles

**Decision:** [ASSUMPTION] Default radius 25 miles; ceiling 50 miles (the validation zone boundary).
**Rationale:** 25 miles covers the densest part of the Marysville/Everett market without overwhelming the feed.

### PRD-006: Discount Display replaces Net Savings dollar figure
**Decision:** v1 shows discount % and Gas Cost side by side ("35% off — $1.80 to get there") rather than a computed Net Savings dollar amount.
**Context:** Deals are published as percentage discounts. Computing a dollar savings requires knowing the user's intended spend, which is unknown. Side-by-side display is honest and avoids anchoring on an invented basket size.
**Open:** OQ-7 and SM-3 exist to validate whether this is sufficient during R&D.

### PRD-007: Banner/sidebar ad constraints sufficient for PRD; slot implementation deferred to UX
**Decision:** §8 Constraints (banner/sidebar only, no pop-ups, not cannabis-branded) is the correct PRD-level detail for advertising. FR-level ad slot spec deferred to UX/design phase.
**Rationale:** Erik confirmed this is sufficient for architecture and stories to work from.
