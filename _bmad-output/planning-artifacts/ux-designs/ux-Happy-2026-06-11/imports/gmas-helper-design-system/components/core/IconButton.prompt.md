**IconButton** — square control for icon-only actions; always give it an `aria-label`.

```jsx
<IconButton aria-label="Settings"><i data-lucide="settings" /></IconButton>
<IconButton aria-label="Close" outlined size="sm"><i data-lucide="x" /></IconButton>
```

Sizes `md` (44px) / `sm` (36px). `outlined` adds a border + white fill for use on tinted surfaces.
