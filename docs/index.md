# Project Documentation Index — gmas list (Happy)

> Generated by **bmad-document-project** (Quick Scan) on 2026-06-21. Primary entry point for AI-assisted development. For architectural rationale see [`../ADR.md`](../ADR.md); for the canonical design/legal spec see [`../GMAS_LIST_BRIEF.md`](../GMAS_LIST_BRIEF.md).

## Project Overview

- **What:** ranks legal WA cannabis deals by **true cost** (sticker price + gas to drive there).
- **Type:** multi-part monorepo with 3 code parts + 1 design reference bundle.
- **Primary languages:** TypeScript (client + server), Python (scraper).
- **Architecture:** single Render Node web service (React build + Express API, one origin); data refreshed out-of-band by an hourly GitHub Actions cron pushing to `POST /api/ingest` (ADR-034).
- **Live:** https://gmaslist.com

## Quick Reference by part

### React Client (`client/`) — web
- **Stack:** React 19, Vite 8, Tailwind v4, TypeScript strict, Vitest.
- **Entry:** `client/src/main.tsx` → `App.tsx`.
- **Pattern:** component hierarchy + local hooks; no global store. Fetches `GET /api/data`, computes true cost, ranks deals.

### Express API + Scrape Pipeline (`server/`) — backend (Node)
- **Stack:** Express 5, TypeScript ESM, axios, cheerio, tsx/tsc, Vitest + supertest.
- **Entry:** `server/index.ts` → `dist/server/index.js`.
- **Pattern:** thin routes over a flat-file store (`data/data.json`), atomic writes under a lock; strict ingest chokepoint.

### Python Scraper (`scraper-svc/`) — backend (Python)
- **Stack:** FastAPI, Uvicorn, Playwright (stealth), curl-cffi, cloudscraper, pytest.
- **Entry:** `scraper-svc/api/server.py` (`uvicorn api.server:app`).
- **Pattern:** tiered fetch (browser / tls / cloudflare) behind `POST /scrape`; booted in-job by CI, not deployed.

### Design System (`design-system/`) — reference
- Tokens / guidelines / theme bundles (Tidewater → Synthwave, ADR-040). Not compiled or deployed.
